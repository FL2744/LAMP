LAMP — LATENT ASSOCIATIVE MEMORY PROGRAMMING
STATIC WEBSITE

Upload LAMP.zip into the document root for l1001.vt.domains (usually public_html/)
and extract it there. The ZIP already contains the LAMP folder. Do not extract
it inside another LAMP folder. If uploading individual files instead, put all
files from this folder into public_html/LAMP/. Capitalization matters. Open:
https://l1001.vt.domains/LAMP/

No PHP, Python, PyTorch, npm install, database, or API key is needed on the server.
Required files: index.html, style.css, app.mjs, engine.mjs, model.json, model.bin, weight-field.svg.
Keep them together. All paths are relative, so a subdirectory works.
The server must serve .mjs as text/javascript (the included .htaccess configures
this on Apache). No visitor data is sent to a backend. Memory is per browser
and origin; export JSON to transfer it. Start each new visitor with blank memory.

Local preview from the parent project:
.venv/bin/python -m http.server 8765 --directory web
Then open http://localhost:8765

This is the actual 77,568-parameter toy transformer ported to JavaScript.
Weights are little-endian float32. Arithmetic uses JavaScript numbers, with
an erf approximation for GELU. All 126 regression predictions match Python;
maximum observed logit difference is approximately 0.0000031.
Memory files contain only numeric matrices, slot settings and model identity.
The writer supports existing one-token answers and explicit user writes.
It does not implement automatic episodic memory or conversation recall.
